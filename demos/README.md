engine CLI. Open a file in a current desktop browser; it runs offline from `file://` with no network access, install or build step.

## Generated files: never edit by hand

This directory is generated by `cd source/wildlands && npm run build:demos`, which builds the `bin/wildlands` candidate and runs
`build-game --game docs/concepts/<id> --output demos/<id>.html` for every game folder. [`manifest.json`](manifest.json) records each
demo's game digest, engine identity, size and SHA-256; this README is generated from it. `npm run check:demos` rebuilds everything
in a temporary directory and fails on any byte difference, missing or orphaned file, or a demo over its `targets.html.budgetBytes`.

Handbook: [Wildlands CLI](../docs/reference/wildlands-cli.md). Editors and export tools are not published here; build a studio
on demand with `bin/wildlands build-game --game docs/concepts/<id> --output studio.html --profile studio`.
