# Littlewild — reusable autonomous-world prototype

This directory is reserved for the self-contained Littlewild showcase and its source.
The work is isolated from the native Motorsport Manager game.

## Current implementation work

- Consistent interface spacing and world-interactive build/tutorial panels.
- Declarative project, world, scene, starting-state and presentation definitions.
- Existing autonomous creatures, research, construction and physical logistics remain the engine foundation.
- Versioned JSON authoring, validation, import/export and regression tests.

This branch is work in progress. The final handoff will record the exact build identity,
executed checks, reproduction commands and remaining limitations. This document does
not assert that an implementation or a verified release has been uploaded yet.
