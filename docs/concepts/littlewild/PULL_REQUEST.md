# Littlewild: code quality, deterministic transactions and verification hardening

Littlewild retains data-driven worlds/creatures and ECS M1–M6. This update fixes transaction and import boundaries, strict CLI behavior, deterministic state validation and verification false positives. Cohesive typed services replace oversized compatibility/UI/renderer modules; all Littlewild source now fits the repository line budgets without exceptions.

The gate checks named evidence, source identity, subprocess cleanup and all-page browser diagnostics. Asset and creature catalogs reject malformed/executable data and expose immutable definitions. Current-only scenario 2/story 10 contracts remain explicit. AJV is pinned to the supported security fix; shared official workflow actions use immutable supported releases.

Validation and exact artifact/input identities are in `VERIFICATION.md` and `delivery-manifest.json`. `QUALITY-AUDIT.md` maps fixes to regression suites. Native gameplay source is unchanged; native legacy advisory findings remain visible. Strict typing debt is explicitly inventoried rather than hidden.
