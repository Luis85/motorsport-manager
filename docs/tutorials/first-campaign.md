# Complete the first campaign loop

This tutorial follows the first event of the **Team Principal Campaign**, then
returns to the Director's Desk and advances toward the second event. You will
learn where campaign time changes, where racing happens and where actual results
become standings, cash and a debrief.

The shipping player route is a **four-event slice**. The desk summarizes work,
rivals and priorities; later recruitment, finance, engineering and dynasty
foundations do not yet have dedicated specialist management screens.

## Before you begin

Open the game and complete [your first standalone weekend](getting-started.md)
so you know how to release both drivers and approve each session. Campaign events
use that same **Minimal** race flow, even if your standalone preference is
Advanced. The campaign supplies its frozen calendar and weekend configuration;
you do not configure a new standalone event for this exercise.

If you already have a campaign, the menu offers **Continue Team Principal
Campaign**. It resumes that career. These steps describe a new career; use the
same loop at your next outstanding event when continuing.

## 1. Read the Director's Desk

1. From the main menu, choose **Team Principal Campaign**.
2. Read **Cash**, **Next event**, **Principal energy** and **Team standing**.
3. Read **Committed minimum cash** at the bottom and the current priorities under
   **Decisions that matter**.
4. Leave the **First campaign loop** guide visible for this exercise. If it is
   hidden, choose **Show guide**.

Before the first race, **Latest debrief** has no completed-weekend evidence. Cash
is your current balance; committed minimum cash is a forecast of binding
obligations, not extra spendable cash. Merely reading the desk does not move
campaign time or settle obligations.

## 2. Reach and start the event

1. If the primary action is **Advance to event**, choose it. This advances campaign
   time to the next scheduled departure and settles obligations due during that
   advance. Read the refreshed desk.
2. When the primary action becomes **Start next event**, choose it.
3. If departure is blocked, read the displayed reason. A rejected readiness check
   leaves the campaign unchanged; do not start a separate standalone weekend as
   a substitute.

A successful departure opens the existing Minimal race workspace. Readiness
checks the scheduled event, accepted entrants, driver/crew availability,
installed car profiles and event costs. Campaign planning freezes during the
active event.

## 3. Complete the existing weekend

Follow the session sequence you learned in the standalone tutorial:

1. **Start practice**, then select each player driver and **Send out**. Use
   **Play** when paused. Let both measured runs finish, then **End practice**.
2. **Start qualifying**, send both drivers once, let their flying laps and returns
   finish, then **End qualifying**.
3. **Start formation**, wait for the cars to take their grid positions, then
   **Start race**.
4. Manage the actual race and wait for the final classification.
5. Choose **Review weekend**.

Campaign racing uses the same tyre stock, physical routes, recorded orders and
race result as standalone racing. Race playback speed changes race time; it does
not advance the desk's dated campaign clock independently.

## 4. Read the debrief and continue

After a successful settlement, you return directly to the Director's Desk.

1. Read **Latest debrief** for the completed round.
2. Compare the updated cash, team standing, completed-event count and next event
   with the values you saw before departure.
3. Read the refreshed priorities and organization/rival summaries.
4. Choose **Advance to event** when offered to reach the next departure, then
   stop at the desk for this exercise.

The debrief reports observed sporting, cash and returned-condition facts.
Settlement applies the completed result once; reopening a report does not earn
another award. If settlement or saving fails, keep the displayed error and use
[troubleshooting](../how-to/troubleshooting.md) before attempting another event.

You have completed the central loop: read the desk, depart, run a real weekend,
settle its result and reach the next decision. Repeat the loop for the remaining
calendar events. This tutorial does not promise a particular championship result
or present later domain foundations as available menu controls.
