# Interaction model

## Decision lifecycle

OBSERVE → NOTICE → REVIEW → COMPARE → COMMIT or KEEP PLAN → ACKNOWLEDGED → EXECUTING → OUTCOME → DEBRIEF.

A decision presentation must include, where available: trigger, evidence, feasible options, uncertainty, deadline and default/ignored behavior.

## Command safety

- Reading never pauses.
- Opening a panel never changes simulation speed.
- Draft edits do nothing until explicit approval.
- Pit calls are validated against the displayed forecast/safe gate.
- Keep plan changes no order unless the domain explicitly records an acknowledgement.
- Disabled actions explain why through tooltip/focus help.
- Command acceptance is echoed in Messages.

## Keyboard

Space pause/resume; 1–5 speed; Ctrl+Tab team driver; B pit selected driver when legal; F fit circuit; Esc close context; F1 focused help; Ctrl/Cmd+K find view.
