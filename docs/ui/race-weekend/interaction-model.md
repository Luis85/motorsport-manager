# Interaction model

## Decision lifecycle

Notice → Review → Compare → Confirm → Accepted/Executing → Observed outcome. Keep plan produces Acknowledged instead of a new racing instruction. A rejected command returns to review with the domain's reason.

The queue and driver identity open the real decision drawer. Its copied view model names the driver, fitted/next set, source time/revision, safe gate, evidence, assumptions, alternatives and current ownership. Pit loss/rejoin/finish fuel remain estimates; observed fuel/set/position remain separately labeled.

The first Box/Save fuel/Release activation stages an exact pending payload. A second activation confirms it. Back to review discards only that UI proposal. Before each activation, the snapshot is checked for material/age/phase changes. Stale evidence disables commitment; only explicit Refresh creates a new snapshot. Rejections never silently replace a set, gate or recipient. Accepted stops remain physical. Full battle context is readable in the drawer, not hover-only.

The existing expert fast paths (driver-card Box and B) retain their domain validation; the drawer does not falsely claim that every command in the game is two-stage. All operations still name their own driver. Time controls change only through deliberate time commands.

## Editing and inspection

Strategy and setup drafts do nothing until their explicit approval/application. The practice dashboard shares per-driver drafts with the compact practice editor; Run commits the displayed finite set/objective/setup through existing validation. Navigation, focus, filtering, chart selection, resizing and inspection are observational. Full workspace close preserves data and returns focus to a visible invoker or Race view.

Radio History freezes its displayed event snapshot; Live resumes newest-first updates. Results distinguish accepted command/model estimates from observed outcomes. A pit visit's duration is not net race-time loss. Original result acceptance, sandbox experiments and notebook notes remain separate actions.

## Inputs

Keyboard: Space pause, 1–5 speeds, Ctrl+Tab team driver, B validated pit call, F fit, Esc close workspace/context, F1 focused help, Ctrl/Cmd+K view finder, Enter native activation.

Controller: native D-pad/A focus and activation; shoulders switch own driver; X review decision; Y finder; B back; Start deliberate pause/resume. Global controller commands are blocked while a modal subwindow is visible. Destructive/race commands are never assigned to a shoulder-selection action.
