# Race overview

## Integrated components

RaceObservationWorkspace + RaceTimingTower + PitwallCarCard + RaceDecisionQueue.

## Information contract

The circuit and public classification dominate. Two independently targeted cards show fitted minimum wheel life, estimated finish fuel, pit ownership/window, driver intent and meaningful attention state. The wide rail includes recent radio; compact mode reuses the same cards below the circuit. Original vector helmet/number emblems provide identity without unlicensed portraits.

## Interaction and safety

Selecting a dot/row is observational. Driver identity opens decision review. Direct Box remains a validated expert action; More retains lower-frequency operations. Header/menu/time controls stay reachable. Empty queue is suppressed only in compact height; review remains available through cards and Find.
