# Layout system

The header and primary task navigation remain stable. Observation is a shared native HBox: timing, circuit, selected-task inspector/own-driver rail. Wide Race view uses the right rail; compact or contextual analysis reuses the same two cards below the circuit. Reparenting occurs only on layout transitions and restores an affected control's focus.

The attention queue is an independent stable two-driver component. At short heights an empty queue is suppressed; material decisions are shown and full review remains reachable from each driver card and Find. This avoids paying permanent vertical space for "no issue".

A focused analysis, two-programme dashboard or full session review is a sibling immediately after the spatial body, above common feedback. It replaces observation space while open. The full inspector/results table is reparented, not cloned; on close it returns to its original parent. Drafts, native Tree selection and model authority therefore survive.

Content may scroll; confirmation/approval/recall/end-session controls remain outside that scroll. Do not use broad horizontal scrolling to compensate for a crowded core layout. Setup numeric fields and sliders share one underlying draft. Inline practice and the full dashboard share the same per-driver draft dictionary.

Long evidence remains readable through task views/scrolling detail and focus help; it is not silently removed to meet a screenshot dimension. Empty and unavailable states are explicit.
