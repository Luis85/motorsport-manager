# Design tokens

## Palette

- Structural chrome: deep racing green.
- Raised chrome: secondary racing green.
- Primary surface: warm cream.
- Interaction accent: brass/gold.
- Healthy: green.
- Warning/opportunity: brass plus text.
- Danger: red plus text/icon.
- Selection: gold border/background treatment.

Color is never the sole carrier of meaning.

## Spacing

The implementation uses PitwallDesign SPACE_1..SPACE_5 (4/8/12/16/24 px) and semantic layout widths. New race UI should not introduce arbitrary local spacing unless a component has a documented reason.

## Typography

Display: event/circuit.
H1: workspace.
H2: panel.
Driver: driver identity.
Position: large P#.
Metric: timing/resource value.
Label: uppercase compact descriptor.
Body: explanation.
Caption: uncertainty/secondary metadata.
