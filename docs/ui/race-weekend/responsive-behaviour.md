# Responsive behavior

The native application retains its 1100×720 minimum. Regression checks exercise 1100×720, 1280×720/800, 1440×900 and selected 1920×1080 layouts across 100/115/130% text.

Wide observation uses the two-car right rail when there is sufficient width/height. Compact observation and inline analysis reuse the same cards below the circuit. Expanded/enlarged-text analysis may temporarily hide classification, never the two real driver actions or time controls. Short-height layouts suppress an empty decision queue and redundant card context to preserve circuit and editing space; urgent content is not discarded.

Full Focus mode reuses the inspector with one recipient/navigation layer. Full practice displays both independently scrollable programme cards; their Run/Recall and shared End controls stay outside evidence scrolling. Results navigation and its classification remain native controls; resizing from full to contextual review resets column widths instead of leaving a wide-layout minimum behind.

No unsupported tablet/touch product or controller certification is implied by the desktop minimum.
