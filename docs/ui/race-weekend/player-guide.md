# Race Weekend player guide

## Start and keep control of time

Choose a circuit and weekend configuration from Grand Prix setup, then review the briefing. The fixed dark header identifies the circuit, session, flag, current weather and time controls. Session approval is a separate gold action. A guide, chart, inspection or warning never pauses the race or changes its speed for you.

Use **Pause / Resume** or **Space** outside an editing control. Keys **1–5** select the five supported speeds. Native controller shortcuts are installed alongside keyboard mappings, not instead of them. A modal dialog owns its input; commands must not pass through to the race underneath it.

The **Weekend** menu opens the resumable guide, help, checkpoint and replay/notebook routes. The guide can be dismissed, resumed or restarted. Its steps reveal existing controls without carrying out sample orders. Pause explicitly before reading when needed.

## Prepare one or both cars

Practice is optional. Open **Strategy → Practice → Dashboard** to see Daniel Mercer and Lucas Moreau together. Each driver chooses one of the four real objectives: tyre-life estimate, qualifying preparation, setup comparison or wet-condition learning. Select that driver's finite tyre set, measured laps and supported setup baseline. These are unapplied drafts; switching between dashboard and inspector preserves the same drafts.

**Run** commits the displayed driver's current preview. It fits the named set and uses actual tyre condition, fuel, health and session time. **Recall** returns through the physical route and retains partial evidence. **End practice** requires confirmation for the shared session. A measured lap is not necessarily a clean, comparable learning sample: read the sample-quality and assumption text. Zero matching clean samples means baseline estimates remain; it is not a hidden performance penalty or a failed data display.

After closure, the dashboard shows retained run results rather than a new run budget. **Return to briefing** is explicit. Qualifying still requires its own approval.

## Qualify in the single supported session

Each car moves through garage, out lap, hot lap and in lap. The circuit and timing tower provide public traffic context. The release summary shows best valid lap and a gap to the fastest valid lap, or **Untimed**. It distinguishes the time needed for a *new* release from the car's active lap. The latest start is expressed in **elapsed session seconds**, not as a promised gap or current-lap countdown.

Open the named driver's run plan to review and confirm release. A driver already running cannot start a second simultaneous run. A closed session cannot start a new timed attempt; an eligible hot lap already underway may finish. Closing qualifying and advancing from its measured results are separate approvals.

## Stage setup and real tyre allocation

**Car → Setup** exposes wing, balance, suspension, cooling and brake bias. The slider and numeric field edit the same per-driver draft. Fitted → draft values and model-derived effects are shown together. **Apply setup** is available only in permitted garage/preparation states. Live race brake bias is a separate validated command, not a back door for mechanical changes.

**Car → Tyres / Wheels** separates fitted set, planned set and available driver-owned stock. A limiting puncture takes precedence over average tread. Selecting a set does not fit it, restore it, or transfer a teammate's allocation. Formation, release and physical service retain the existing fitting rules. The detailed wheel inspector explains actual retained condition; there is no individual wheel-service animation claiming measurements the model does not record.

Leaving the view with genuine strategy, setup or practice edits requires an explicit discard decision. Defaults alone do not cause an abandonment warning. Canceling that warning preserves the original weekend and drafts.

## Compare, approve and intervene

**Strategy → Compare / Plan / Control** reuses one strategy draft and the existing command boundary. Candidate forecasts are estimates, not promised finishing positions. The optional stint chart has a distance-lap ruler and keyboard/pointer inspection. Up/down selects an option; left/right selects a supplied stop. Inspecting does not approve it.

An **approved window** delegates timing inside that accepted plan. It is not an immediate pit order. **Team → Plans** puts both drivers' accepted windows and already-issued bounded pace/engine overrides on one shared distance axis. It is read-only. Review links return to the existing planning controls; the timeline cannot schedule arbitrary future commands.

The stable decision queue counts every unacknowledged issue for each driver. Open a slot and select a secondary issue when needed. The drawer pins the reviewed driver, set, gate and evidence. Choose an action, read its confirmation, then confirm it. Changing global inspection does not silently redirect the order. Stale evidence must be refreshed explicitly; a rejected action is not replaced with a different order.

**Keep plan** acknowledges the displayed issue without calling a pit stop, taking ownership or changing time. Acceptance, physical execution and outcome are distinct. A fuel-saving override can complete by expiry or be superseded; a qualifying run can complete with an invalid lap. Completion is not a claim that the decision improved the result. Reopening an accepted receipt does not submit it again.

## Watch a physical stop

Open **Team → Pit box**, or the driver's **More → Open pit service** route. Approach, entry, queue, service, exit and completed visit reflect the real route and journal. Cancellation is legal before entry and disabled afterward. Priority cannot reorder cars already physically committed.

The service bar represents one whole-car service timer. It does not include all pit-lane transit and is not four wheel timers. Fitted/planned and frozen service choices are distinguished. The measured completed visit is correlated to its entry/exit record, not inferred from a larger pit count. Retirement interrupts an uncompleted approach or visit. Qualifying/practice transit is explicitly not a race pit service.

## Inspect evidence without interfering

**Focus** moves the same inspector into a larger workspace; it does not clone drafts. Both named driver targets and the fixed time controls remain reachable. **Back to pit wall**, Escape or the supported native B route restores context without issuing an order.

Telemetry has four recorded channels: speed (km/h), tyre tread (%), remaining fuel (lap units), acceleration (m/s²). Choose a retained range, inspect with left/right or Home/End, and optionally compare your teammate. Solid circles and dashed squares distinguish the traces. Only exact compatible timestamps are aligned; absent samples remain gaps. Current engine/brake temperatures are labeled current model state, not invented histories. Rival inspection masks private data.

Weather separates observed rainfall/road water, sector conditions, public uncertain outlook, independent same-horizon cases and feasible alternatives. The cases are not probabilities or a future time trace. Sector inspection and surface overlays are observational. A weather Box action uses the existing reviewed/validated order route; opening an outlook does not issue it.

Radio presents bounded retained events. **History** freezes a reading snapshot; incoming live events do not move its page or focus. **Live** returns explicitly to the newest events. **Messages** is a separate bounded history of local acknowledgements/errors, not a sporting outcome record.

## Finish, explain and preserve the original

Results retain classification, measured laps/sectors, fitted stints and correlated pit visits. Invalid and pit laps remain identified rather than disappearing or setting a false fastest lap. Practice durations use recorded lap seconds, not absolute crossing timestamps. Teammate comparisons do not establish controlled causal attribution.

Open **Decisions / Debrief** for accepted instructions, estimates at the time and measured consequences. Notebook, evidence export and replay remain available. **Accept original result** is an explicit once-only route for an eligible original; a sandbox cannot settle or replace it. Another weekend never starts simply because a report was opened.

## Supported desktop presentation

The full populated screen set is checked at 1440×900 / 100%, 1280×800 / 115%, and 1100×720 / 130%. Primary tasks additionally sweep 100/115/130% at all three sizes and 1920×1080 at 100/130%. Evidence may scroll; critical actions are outside that scroll. Text above 130%, mobile/touch layouts, actual controller hardware and Windows screen-reader behavior are not certified by these checks.
