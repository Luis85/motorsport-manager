# Accessibility contract

- Important states combine text/symbol/shape with color.
- Keyboard focus is always visible.
- Hover help is duplicated by focus + F1.
- 100%, 115% and 130% pit-wall text scales are supported.
- Reduced motion disables smooth follow transitions.
- No hover-only command.
- No auto-pause caused by alerts or reading surfaces.
- Player cars are identifiable by short code and position, not team color alone.
- Decision severity uses explicit labels such as WARNING, PIT, TYRE or CAR where applicable.
