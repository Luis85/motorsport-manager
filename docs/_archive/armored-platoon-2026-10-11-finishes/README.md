## Failures and limits retained

The initial plain-array HTML exceeded the existing 8 MiB target. Lossless
canonical base64 reduced transport size without reducing geometry, texture
pixels or budgets. Native execution caught numeric JSON/dictionary identity and
omitted/default-white palette equivalence issues. Independent review caught
partial map allocation leaks, disposal drain failure and effective override
admission/accessor problems; regressions cover the fixes.

Initial Forge E2E launch failed because the default Playwright browser was absent.
The supported system-browser setting passed Model Forge's four browser checks.
Scene Forge's seven file-navigation cases were blocked by this environment's
`ERR_BLOCKED_BY_ADMINISTRATOR`; the existing inline-HTML harness passed all 15,
without claiming actual file-URL launch acceptance. Initial logs are retained.

Two Python runs from the active worktree failed seven source-staging checks:
recursive source digests included mutable work, generated output and logs.
These are recorded as failed attempts. A clean detached pinned-native run is
required before claiming full Python acceptance. The superseded pre-merge long
observation was deliberately interrupted after 156 seconds and is not a
30-minute pass.

All local rendering is software WebGL. Installed-reference timings, production
assets/content, hardware performance, full device coverage, multiplayer and the
remaining parity ledger are unaccepted. Procedural finish wear is generic surface
detail, not authored edge wear or a combat-damage texture system.
